# Shane Rafol React Portfolio

This is the original portfolio UI, now mounted and managed by React 18 + Vite. The existing HTML markup and styles are retained; only the Web Development project cards were expanded from 3 to 8. Navigation and dropdown interactions are initialized in a React effect.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to GitHub Pages
The repository can be deployed through GitHub Actions using the included workflow. Enable **Settings → Pages → Build and deployment → GitHub Actions**.

Note: Some external websites may block iframe previews; the **Open Full Website** link still opens them normally.
